## 权限验收

- 无 token：`401`
- 普通用户访问 admin/runtime/module installer：`403`
- 管理员：允许查看状态和生成计划。

## 运行边界

Web Shell 只查看状态和计划。安装、启用、禁用和 runtime apply 使用原生 CLI/TUI。
