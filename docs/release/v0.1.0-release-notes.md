# OJOS v0.1.0 发布说明

发布日期：2026-06-28

OJOS v0.1.0 是题库、评测、Judge Core、Kernel、Module Runtime、Installer 和 Module SDK 的正式发布基线。该版本适合本地或单机 Docker Compose 环境验收和二次开发，不声明生产完全安全，也不声明 full hotplug 完成。

## 可发布能力

- 题库管理：题目列表、详情、创建、编辑、测试点和题目包校验。
- 评测链路：提交创建、队列、worker 领取、结果回传、用例结果查看、重测和取消。
- Judge Core 模块边界：通过 manifest 进入 Runtime Snapshot、Gateway route、service、worker 和 topology。
- Kernel Installer：manifest 校验、package/verify、install plan、enable/disable plan、operation history。
- Module Runtime：runtime snapshot、routes、services、workers、health、受控 runtime plan。
- Controlled Apply：`ojosctl runtime apply-plan` 支持 `--dry-run` 和 `--confirm`，只允许 trusted compose allowlist。
- Module SDK：`ojosctl module init`、sample module、compatibility harness。
- 原生安装入口：`ojosctl` 和 `ojos-installer-tui`。
- Web Shell：状态、题库、评测、模块、runtime、topology 和权限管理视图。

## 不可发布能力

- Contest 尚未实现。
- L3 dynamic frontend bundle 未完成。
- hooks 未实现。
- remote module market 未实现。
- full hotplug 未完成。
- package signature / trust policy 未完成。
- true multi-machine runtime apply 未完成。
- Judge Core 不标记 GA。

## 安装入口

正式安装、打包、验证、启用、禁用和 runtime apply 使用：

```powershell
cargo run -p ojosctl -- doctor
cargo run -p ojos-installer-tui --
```

Web Shell 只作为管理视图，不作为官方安装器主入口。

## 安全边界

- Gateway/Web 不挂载 Docker socket。
- Gateway/Web 不直接 apply runtime plan。
- manifest 不允许 command、script、hook、image、mount、host_path、privileged、cap_add、target_url。
- runtime apply 必须有 plan、TTL、allowlist、lock、timeout、operation history 和二次确认。
- path leak 验收必须保持 `path_leaks=0`。
