# OJOS v0.1.0 发版清单

## 必须通过

- `powershell -NoProfile -File scripts\acceptance-kernel.ps1 -SkipDockerBuild`
- `powershell -NoProfile -File scripts\acceptance-kernel.ps1 -RunControlledApply -SkipDockerBuild`
- `powershell -NoProfile -File scripts\verify-static.ps1 -SkipDockerBuild`
- `powershell -NoProfile -File scripts\e2e-api.ps1 ...`
- `powershell -NoProfile -File scripts\e2e-module-compat.ps1 ...`
- Go 多模块 `go test ./...`
- Rust root `cargo fmt --check && cargo check && cargo test`
- judge-worker `cargo fmt --check && cargo check && cargo test`
- frontend `npm audit --registry=https://registry.npmjs.org --audit-level=high && npm run build`
- `powershell -NoProfile -File scripts\build-release-artifacts.ps1 -Version v0.1.0`

## 必须确认

- `failed=0`
- `path_leaks=0`
- `admin_health_status=ok`
- `admin_health_judge_status=ok`
- `sample_module_compat=passed`
- ordinary user 为 `403`
- no token 为 `401`
- problem-api、judge-api、judge-worker 健康。
- module-installer healthy，gateway running。
- `.env/.tmp/target/.ojosmod/token/logs/frontend/dist` 不进入 Git。

## 发版前不得出现

- Contest API、Contest 前端、Contest migration。
- Judge Core GA 描述。
- full hotplug 完成描述。
- 真实 secret、本机绝对路径、临时构建产物。
