# OJOS v0.1.0 Release Artifacts

构建命令：

```powershell
powershell -NoProfile -File scripts\build-release-artifacts.ps1 -Version v0.1.0
```

默认输出目录：

```text
.tmp/release/v0.1.0/
```

产物：

- `bin/ojosctl.exe`
- `bin/ojos-installer-tui.exe`
- `packages/sample-hello.ojosmod`
- `frontend/dist/`
- `checksums.sha256`
- `artifact-manifest.json`
- release notes / ship checklist / acceptance report / known limitations 文档副本。

Docker 镜像由 compose build 生成：

- gateway
- auth
- problem-api
- judge-api
- judge-worker
- module-installer

如遇网络或镜像构建失败，必须在发版报告中写为失败或跳过原因，不能写成通过。
