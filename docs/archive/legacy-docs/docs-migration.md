## 保留原则

- 正式文档只描述当前真实状态。
- 历史过程进入 `docs/archive/`。
- 未来规划进入 `docs/features/` 或 `docs/roadmap/`。
- 无法作为当前依据、且正式文档已覆盖的旧稿不继续保留。
